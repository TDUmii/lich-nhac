# Lich Nhac

A friendly Windows calendar reminder app built with WPF and .NET 8.

## Features

- Upcoming calendar view
- Custom reminder characters
- Sound toggle
- Test reminder action
- Google Calendar integration scaffold

## Run

```powershell
dotnet run --project .\LichNhac.csproj
```

## Status

The current build is an MVP. The Google Calendar button is a UI demo. OAuth, token storage, background sync, and Windows toast notifications are planned next.
